# VolatileHook

[Git Source](https://github.com/Uniswap/v4-hooks-public/blob/d695b82e1989fd37810331b03e453e131404c179/src/volatile/VolatileHook.sol)

**Inherits:** [BaseDynamicFeeHook](/src/base/abstract.BaseDynamicFeeHook), [VolatileFeeConfiguration](/src/volatile/base/abstract.VolatileFeeConfiguration), [IVolatileHook](/src/volatile/interfaces/interface.IVolatileHook)

**Title:** VolatileHook

Dynamic fee hook for volatile pairs (v2 skew + backrun algorithm); UUPS proxy is the
registered v4 hook. The fee math lives in VolatileFeeCalculation; this contract loads
state, calls it, and stores.

<i>

Ask = a buy = zeroForOne false; bid = a sell = zeroForOne true.

</i>

**Note:**

- **security-contact:** security@uniswap.org

<a id="_loadtopofblockstate-poolid"></a>

### _loadTopOfBlockState

Loads a pool's state, advancing it to this block's baselines in memory without writing.

<i>

New block: recomputes baselines from the price impact since the previous open and caches
the new open. Same block: returns the stored values unchanged.

</i>

```solidity
function _loadTopOfBlockState(PoolId _poolId)
        private
        view
        returns (VolatileHookState memory poolState, uint160 currentSqrtPriceX96, bool isNewBlock);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _poolId | `PoolId` | Pool id |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolState | `VolatileHookState` | Config + state, advanced if isNewBlock |
| currentSqrtPriceX96 | `uint160` | Pool's current sqrt price |
| isNewBlock | `bool` | True on the first swap of a new block, or right after a config reset |

<a id="_getfee-volatilehookstate-uint160-bool"></a>
