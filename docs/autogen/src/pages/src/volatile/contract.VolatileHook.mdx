**Title:** VolatileHook

Dynamic fee hook for volatile pairs (v2 skew + backrun algorithm); UUPS proxy is the
registered v4 hook. The fee math lives in VolatileFeeCalculation; this contract loads
state, calls it, and stores.

<i>

Ask = a buy = zeroForOne false; bid = a sell = zeroForOne true.

</i>

**Note:**

- **security-contact:** security@uniswap.org

<a id="getfee-poolkey"></a>

### getFee

The LP fee a swap would be charged this block, per direction.

<i>

The returned fee MUST be size-independent: it does not depend on the swap amount.
A hook whose fee depends on swap size MUST revert here instead of returning a misleading value

</i>

```solidity
function getFee(PoolKey calldata key) external view returns (uint24 feeE6ZeroForOne, uint24 feeE6OneForZero);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| key | `PoolKey` | The PoolKey of the pool |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| feeE6ZeroForOne | `uint24` | The fee for a zeroForOne swap this block |
| feeE6OneForZero | `uint24` | The fee for a oneForZero swap this block |

<a id="_loadtopofblockstate-poolid"></a>

### _loadTopOfBlockState

Loads a pool's state, advancing it to this block's baselines in memory without writing.

<i>

New block: recomputes baselines from the price impact since the previous open and caches
the new open. Same block: returns the stored values unchanged.

</i>

```solidity
function _loadTopOfBlockState(PoolId _poolId)
        private
        view
        returns (VolatileHookState memory poolState, uint160 currentSqrtPriceX96, bool isNewBlock);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _poolId | `PoolId` | Pool id |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolState | `VolatileHookState` | Config + state, advanced if isNewBlock |
| currentSqrtPriceX96 | `uint160` | Pool's current sqrt price |
| isNewBlock | `bool` | True on the first swap of a new block, or right after a config reset |

<a id="_getfee-volatilehookstate-uint160-bool"></a>

### _getFee

Fee one swap direction pays, escalated from the block's baseline by in-block displacement.

<i>

Never reads the swap amount; size-independence is what makes `getFee` well defined.

</i>

```solidity
function _getFee(VolatileHookState memory _poolState, uint160 _currentSqrtPriceX96, bool _zeroForOne)
        private
        pure
        returns (uint24);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _poolState | `VolatileHookState` | Pool's config + top-of-block fee state |
| _currentSqrtPriceX96 | `uint160` | Pool's current sqrt price |
| _zeroForOne | `bool` | Swap direction |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| &lt;none&gt; | `uint24` | Fee for this direction, clamped to VolatileFeeCalculation.MAX_HOOK_FEE_E6 |
