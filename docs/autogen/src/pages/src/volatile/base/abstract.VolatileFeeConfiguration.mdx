<a id="_updatefeeconfig-poolid-volatilefeeconfig"></a>

### _updateFeeConfig

Validates the config, stores it, and resets the pool's fee state to neutral.

<i>

Bounds hold askPermFeeE6 in [restingSpreadE6 - maxSkewE6, maxSkewE6]; the reset to
restingSpreadE6 / 2 re-establishes it on every write.
Also resets sqrtPriceTopX96 to 0, so price impact is treated as 0 until the first swap.

</i>

```solidity
function _updateFeeConfig(PoolId _poolId, VolatileFeeConfig calldata _feeConfig) internal;
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| _poolId | `PoolId` | Pool to configure |
| _feeConfig | `VolatileFeeConfig` | New config |
