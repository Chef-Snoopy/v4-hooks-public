# VolatileFeeCalculation

[Git Source](https://github.com/Uniswap/v4-hooks-public/blob/d73b315559a4ee7a23970fc71b175a27b8f69694/src/volatile/libraries/VolatileFeeCalculation.sol)

**Title:** VolatileFeeCalculation

Pure math for the volatile dynamic-fee algorithm. All `*E6` values are E6 pips; 1e6 = 100%.

<i>

Rounding favours LPs: every division that feeds a charged fee rounds up, and the sqrt-ratio
intermediates in relativeMoveE6 round down because a smaller ratio means a larger move.

</i>

## Constants

### ONE_E6

1e6 is 100% in pips format

```solidity
uint256 constant ONE_E6 = 1e6;
```

### MAX_HOOK_FEE_E6

Maximum LP fee the hook can charge. Pool.swap combines the LP fee with the protocol fee.
Hook fee of 999_999 compounds to 1e6 for any nonzero protocol fee, whereas 999_998 hits
999_999 for any non-zero protocol fee.

```solidity
uint256 internal constant MAX_HOOK_FEE_E6 = 1e6 - 2;
```

### Q48

Scale for the sqrt-ratio intermediate calculation

```solidity
uint256 internal constant Q48 = 2 ** 48;
```

## Functions

<a id="relativemovee6-uint160-uint160"></a>

### relativeMoveE6

Relative move between two sqrt prices, as an E6 fraction of the reference price.

```solidity
function relativeMoveE6(uint160 sqrtPriceNewX96, uint160 sqrtPriceRefX96)
        internal
        pure
        returns (uint256 moveE6, bool increased);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| sqrtPriceNewX96 | `uint160` | Current/new sqrt price |
| sqrtPriceRefX96 | `uint160` | Reference sqrt price (denominator) |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| moveE6 | `uint256` | Relative move magnitude |
| increased | `bool` | True if sqrtPriceNewX96 > sqrtPriceRefX96 |

### newPermanentFee

```solidity

        uint24 oldPermFeeE6,
        uint256 blockPriceImpactE6,
        uint24 skewRateE6,
        uint24 maxSkewStepE6,
        uint24 maxSkewE6
    ) internal pure returns (uint24 newPermFeeE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| oldPermFeeE6 | `uint24` | Previous block's permanent fee for the leaning side |
| blockPriceImpactE6 | `uint256` | Price impact magnitude (>= 0) |
| skewRateE6 | `uint24` | Lean per unit of price impact |
| maxSkewStepE6 | `uint24` | Per-block skew step cap |
| maxSkewE6 | `uint24` | Skew ceiling |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| newPermFeeE6 | `uint24` | New permanent fee for the leaning side |

**Parameters**

| Name | Type | Description |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| newAskPermFeeE6 | `uint24` | New permanent ask-side fee to store |

| bidBaselineFeeE6 | `uint24` | Bid-side baseline for the block |
