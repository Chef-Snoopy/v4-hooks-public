<a id="mulup-relativemove-uint256"></a>

### mulUp

`rateE6 * move`, rounded up. An E6 rate gives E6 pips. This is the only rounding on the fee path.

<i>

rateE6 &lt; 2**24 and numerator &lt; 2**128, so the product fits 256 bits.

</i>

```solidity
function mulUp(RelativeMove move, uint256 rateE6) internal pure returns (uint256);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| move | `RelativeMove` |  |
| rateE6 | `uint256` |  |
