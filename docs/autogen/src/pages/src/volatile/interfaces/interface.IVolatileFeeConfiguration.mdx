<a id="feeconfig-poolid"></a>

### feeConfig

Fee config for a pool.

```solidity
function feeConfig(PoolId poolId)
        external
        view
        returns (
            uint24 restingSpreadE6,
            uint24 backrunCaptureFractionE6,
            uint24 midFadeRateE6,
            uint24 maxMidFadeE6,
            uint24 skewRateE6,
            uint24 maxSkewStepE6,
            uint24 maxSkewE6,
            uint24 backrunThresholdE6,
            uint24 restoreFractionE6,
            uint24 restoreThresholdE6
        );
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolId | `PoolId` | Pool to query |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| restingSpreadE6 | `uint24` | Permanent pie: ask + bid fee |
| backrunCaptureFractionE6 | `uint24` | LP share of backrun profit |
| midFadeRateE6 | `uint24` | Continuing-fee growth rate per unit move |
| maxMidFadeE6 | `uint24` | Cap on the continuing fade |
| skewRateE6 | `uint24` | Baseline lean per unit of price impact |
| maxSkewStepE6 | `uint24` | Max skew change per block |
| maxSkewE6 | `uint24` | Skew ceiling |
| backrunThresholdE6 | `uint24` | Price impact threshold at which the backrun fee component is active |
| restoreFractionE6 | `uint24` | Share of the backrun side's permanent fee drop that the temp fee adds back; 1e6 = all of it |
| restoreThresholdE6 | `uint24` | Price impact threshold at which the restore fee component is active |

<a id="feestate-poolid"></a>

### feeState

Fee state for a pool.

```solidity
function feeState(PoolId poolId)
        external
        view
        returns (uint40 blockNumber, uint160 sqrtPriceTopX96, uint24 askPermFeeE6, uint24 tempFeeE6, bool tempOnBid);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| poolId | `PoolId` | Pool to query |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| blockNumber | `uint40` | Block of the last update. 0 if no swaps since last config update |
| sqrtPriceTopX96 | `uint160` | Block-open sqrt price. 0 if no swaps since last config update |
| askPermFeeE6 | `uint24` | Permanent ask-side fee; bid perm = restingSpreadE6 - askPermFeeE6 |
| tempFeeE6 | `uint24` | One-block backrun charge; baselines follow via VolatileFeeCalculation.baselineFee |
| tempOnBid | `bool` | True if tempFeeE6 is on the bid side, false if on the ask side |

## Errors

### RestingSpreadCannotBeZero

Thrown when restingSpreadE6 is 0, the sentinel for an unconfigured pool

```solidity
error RestingSpreadCannotBeZero();
```

### MaxSkewTooLarge

Thrown when maxSkewE6 exceeds restingSpreadE6, which would let one side's fee exceed the whole spread

```solidity
error MaxSkewTooLarge(uint24 maxSkewE6, uint24 restingSpreadE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| maxSkewE6 | `uint24` | The submitted skew ceiling |
| restingSpreadE6 | `uint24` | The submitted resting spread |

### MaxSkewTooSmall

Thrown when maxSkewE6 is below restingSpreadE6 / 2, the neutral center the leaning side starts from

```solidity
error MaxSkewTooSmall(uint24 maxSkewE6, uint24 restingSpreadE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| maxSkewE6 | `uint24` | The submitted skew ceiling |
| restingSpreadE6 | `uint24` | The submitted resting spread |

### RestingSpreadTooLarge

Thrown when restingSpreadE6 exceeds 2 * MAX_FEE_E6, the sum of both sides' fee ceilings

```solidity
error RestingSpreadTooLarge(uint24 restingSpreadE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| restingSpreadE6 | `uint24` | The submitted resting spread |

### MaxSkewAboveMaxFee

Thrown when maxSkewE6 exceeds MAX_FEE_E6; the excess is skew band the fee clamp would remove

```solidity
error MaxSkewAboveMaxFee(uint24 maxSkewE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| maxSkewE6 | `uint24` | The submitted skew ceiling |

### MaxSkewStepTooLarge

Thrown when maxSkewStepE6 exceeds 2 * maxSkewE6 - restingSpreadE6, the width of the permanent-fee band

```solidity
error MaxSkewStepTooLarge(uint24 maxSkewStepE6, uint24 maxSkewE6, uint24 restingSpreadE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| maxSkewStepE6 | `uint24` | The submitted per-block skew step cap |
| maxSkewE6 | `uint24` | The submitted skew ceiling |
| restingSpreadE6 | `uint24` | The submitted resting spread |

### MaxMidFadeTooLarge

Thrown when maxMidFadeE6 exceeds MAX_FEE_E6; baseline + fade must fit a uint24

```solidity
error MaxMidFadeTooLarge(uint24 maxMidFadeE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| maxMidFadeE6 | `uint24` | The submitted continuing-fade cap |

### FractionTooLarge

Thrown when backrunCaptureFractionE6 or restoreFractionE6 exceeds 1e6 (100%)

```solidity
error FractionTooLarge(uint24 fractionE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| fractionE6 | `uint24` | The submitted fraction |

### ThresholdTooLarge

Thrown when backrunThresholdE6 or restoreThresholdE6 is 1e6 (100%) or more; a down move can never reach it

```solidity
error ThresholdTooLarge(uint24 thresholdE6);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| thresholdE6 | `uint24` | The submitted threshold |

### LengthMismatch

Thrown when poolIds and feeConfigs arrays have different lengths

```solidity
error LengthMismatch();
```
